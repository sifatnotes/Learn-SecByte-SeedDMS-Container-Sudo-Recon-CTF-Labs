# Learn SecByte SeedDMS, Container, Sudo & Recon CTF Labs

A focused collection of hands-on cybersecurity and CTF labs from Learn SecByte covering hidden web paths, port and service reconnaissance, version discovery, container security, SeedDMS enumeration, Sudo security, credential reuse, and shell stabilization.

These labs are useful for cybersecurity students, CTF players, penetration testers, SOC analysts, and security learners developing practical reconnaissance and Linux security skills.

## Introduction

Effective security testing starts with understanding the target environment. Reconnaissance can reveal exposed services, application paths, versions, authentication surfaces, and potential privilege boundaries.

This repository organizes Learn SecByte labs around web discovery, network reconnaissance, container security, SeedDMS, Linux privilege escalation, credential reuse, and shell management.

## Learning Path

A practical sequence for this collection is:

1. Start with **Hidden Paths Open Doors** for web-path discovery.
2. Continue with **Port Sleuth Version Hunt** and **Port Shadow Recon** for network reconnaissance.
3. Study **Container Drift** and **Lock It Down** for container security and defensive configuration.
4. Explore **SeedDMS Flag Chase**, **SeedDMS Sneak Path**, and **SeedDMS User Enum Chase** for application enumeration.
5. Progress to **SeedDMS Root Run** for a web-to-root exercise.
6. Study **Sudo Snooping** for Linux privilege-boundary analysis.
7. Explore **Reuse and Roost** for credential-reuse concepts.
8. Finish with **Shellforge Stabilize the Foothold** to practice shell management.

## How to Use the Labs

- Use all exercises only in authorized and controlled environments.
- Begin with reconnaissance before exploitation.
- Record discovered ports, services, application paths, and versions.
- Analyze authentication and user-enumeration surfaces carefully.
- Study SeedDMS behavior within the provided lab environment.
- Review Sudo permissions before attempting privilege escalation.
- Treat credentials discovered in labs as lab-only information.
- Practice shell stabilization only on systems you are authorized to control.
- Document findings and consider appropriate defensive mitigations.
